# XATUer 2.0 小范围测试

测试入口：[XATUer 今天吃什么](https://rakka-r1a.github.io/XATUer_select_food/)。无需注册，也不需要安装应用。

这是选餐工具与个人手记的测试版，当前没有真实账号、公开动态或多人评论。手记和收藏只保存在自己的浏览器里。

## 花几分钟试试

1. **打开页面**：分别尝试校园网和手机流量，留意首页、照片是否能正常加载。首次打开需要联网。
2. **按楼层选餐**：分别选择一楼、二楼、三楼。不限品类且不只看收藏时，应有 14、18、11 组可选。
3. **换一家**：先限制楼层或品类，再连续换几家；结果应保持在当前范围内，同轮抽完前不重复。只有一家时，重抽仍是同一家。
4. **找店与收藏**：在“逛档口”搜索一家店，查看照片并收藏，再试“只从收藏中选”。空收藏应提示没有候选，不应扩大到全食堂。
5. **记下这一顿**：选中后点“就吃这家”，在“我的”查看记录；保存一份手记，再刷新，检查收藏、记录和手记是否保留。
6. **核对资料**：留意错名、错楼层、重复或已关闭的店。详情里的修正只影响本机；想改公共资料，请另行反馈。
7. **按需测试备份与离线**：先导出记录。导入会在确认后替换本机记录，勿用重要记录冒险测试。联网访问后可试离线重开；没看过的照片可能仅显示图标。添加桌面入口因浏览器而异。

## 怎么反馈

可以把结果直接告诉项目维护者，或到 [GitHub Issues](https://github.com/Rakka-r1a/XATUer_select_food/issues) 提交。建议包含：

- 手机 / 电脑型号、系统和浏览器名称。
- 使用校园网、Wi-Fi 还是手机流量。
- 具体操作步骤、原本期望的结果、实际发生了什么。
- 如涉及档口，提供显示名称、楼层与正确情况。
- 如方便，附上问题页面截图，先遮住私人信息。

不需要发送账号密码、学号或完整浏览器数据，也不要公开上传含私人手记的备份文件。

## 当前已知边界

- 一组招牌可能包含相邻窗口，不等同于精确档口编号。
- 少数店名待进一步核对；照片不代表实时营业。
- 本机记录不会自动跨设备同步。
- 资料修正、手记与昵称不是全站共享数据。
- 当前没有学校周边店铺数据、真实登录、多人评论或 APK。
