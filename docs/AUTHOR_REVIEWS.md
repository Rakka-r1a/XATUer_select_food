# 发布作者点评

普通访客不用注册或登录，只能在网站阅读作者点评。作者用已有的 **Rakka-r1a** GitHub 账号发布，不需要申请新网站账号，也不要把密码或访问令牌填到网站里。

## 第一次发布

1. 在网站打开一家档口的详情，找到“作者点评”。
2. 点“作者写点评（GitHub登录）”。未登录时先在 GitHub 登录自己的作者账号。
3. 发布页已经填写标题和第一行档口标记，例如 `<!-- xatuer-author-review:stall-061 -->`。保留这一行，在其下方写自己的实际点评。
4. 提交后等待 GitHub Actions 自动同步和网站发布，再回网站点“刷新点评”。内容会出现在该档口详情和校园广场的“作者的觅食点评”中，所有访客可见。

不要将密码、令牌或私人联系方式写进点评。这里发布的是公开内容，不是个人手记。

## 修改或撤下

- 每家档口建议维护一条点评。在网站点“查看原文 / 作者编辑或撤下”，登录作者账号后编辑原文。
- 在 GitHub 关闭该条 Issue，可撤下对应点评。回网站刷新即可核验。多条点评按最近更新时间取一条；最新记录被关闭或清空后，不会自动显示更旧的记录。
- 网站按 GitHub 返回的稳定用户 ID `196425000` 核验作者。只改昵称、头像或复制标题和标记，都不会获得作者身份；其他账号提交的 Issue 不会显示为作者点评。
- 作者发布后，GitHub Actions 会用仓库临时令牌读取、核验并更新本站点评文件，随后请求 Pages 发布。访客读取本站文件，不使用 GitHub 匿名 API。若未及时更新，可在仓库 Actions 的“同步作者点评”查看状态或手动运行。刷新前已读取的点评可能仍在本次会话内展示，不代表重新同步成功。

## 与个人手记的区别

“作者点评”从 GitHub 核验后同步到本站，是公开内容；原有“我的觅食手记”、收藏、就餐记录和本机修正继续只保存在当前浏览器。普通访客的手记不会自动发布为作者点评，也不会上传到 GitHub。

## 浏览量

页脚“不蒜子”浏览量统计本站入口页的访问次数（PV），从接入后累计，不能补回此前历史流量，也不是独立访客数。刷新会重复计数；隐私设置、拦截和服务故障都可能使结果不完整。本机预览和非官方镜像不计入正式网站统计，不伪造本机计数冒充全站数据。
