# XATUer 今天吃什么

西安工业大学校园觅食小工具。选一家，去吃饭。

**[打开网站](https://rakka-r1a.github.io/XATUer_select_food/) · [反馈问题](https://github.com/Rakka-r1a/XATUer_select_food/issues) · [内测指南](docs/TESTING.md) · [更新日志](CHANGELOG.md)**

本次更新：**2.0.1 小范围测试版**，发布记录见更新日志。无需注册，手机和电脑浏览器均可使用。

## 能做什么

- **帮你选一家**：按楼层、餐食种类筛选，也可以只在收藏中随机选择。
- **换一家，范围不变**：保留当前条件，每轮抽完之前不重复。
- **逛真实档口**：浏览 46 张实拍照片，查看招牌、搜索名称或餐食品类。
- **记下吃过什么**：点“就吃这家”留下就餐记录，也能收藏、写手记和保存草稿。
- **补充资料**：在档口详情中修正名称、楼层，或把已关闭的店排除出本机随机池。
- **带走本机记录**：导出 / 导入 JSON 备份。支持 PWA 安装入口和已访问资源的离线缓存。

## 怎么用

1. 打开网站，在“去觅食”选择楼层与餐食种类，不限条件就保留“全食堂”和“全部”。
2. 点“帮我选一家”，看招牌照片；想换口味就点“换一家”。
3. 确定后点“就吃这家”。在“我的”查看记录，在“校园广场”写自己的觅食手记。

也可以直接进入“逛档口”，搜索或收藏喜欢的店，再从收藏里选。

## 内测范围与隐私

**当前没有真实账号、公开发帖或多人评论。“校园广场”是个人手记的本机体验，别人看不到你的手记。**

昵称、收藏、记录、草稿和资料修正通过 `localStorage` 保存在当前浏览器，不会由应用上传到服务器。换设备或换浏览器不会自动同步；清理网站数据可能丢失记录，请按需在“我的”导出备份。资料修正也只影响本浏览器，正式公共数据需要维护者更新。

应用不接入统计、广告脚本，不收集学号、手机号、密码或精确位置。静态托管服务仍可能保留访问所需的网络日志。请勿在手记里保存密码等敏感信息，也不要把含个人记录的备份上传到公开仓库。

这轮重点测试楼层筛选、抽取范围、照片资料、手机操作和刷新后的记录保留。具体步骤见 [内测指南](docs/TESTING.md)。

## 本地运行

需要 **Node.js 20 或更新版本**。项目没有第三方 npm 依赖。

```sh
git clone https://github.com/Rakka-r1a/XATUer_select_food.git
cd XATUer_select_food
npm start
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。默认只监听本机。也可直接打开 `index.html` 使用主要功能，但 PWA 和离线缓存需要 localhost 或 HTTPS。

```sh
npm test
npm run check
```

自动检查涵盖楼层覆盖、筛选边界、同轮不重复、关闭档口排除、备份校验、相对资源路径和离线缓存隔离。浏览器呈现、安装与真机体验仍需要人工测试。

## 项目结构与部署

```text
index.html                页面结构；保留 V1 原始代码注释
styles.css                手机与电脑布局
scripts/data.js           档口、照片与楼层资料
scripts/core.js           筛选、抽取与本机数据校验
scripts/dialog-navigation.js 弹窗返回历史与焦点管理
scripts/app.js            页面交互与本机记录
scripts/serve.cjs          本地静态预览服务
scripts/check.cjs          语法、资源与编码检查
scripts/prepare-images.ps1 Windows 图片压缩与图标准备
assets/stalls/            网页实拍图片副本
sw.js                     离线缓存
manifest.webmanifest      PWA 安装信息
tests/                    自动测试
docs/TESTING.md           小范围测试指南
```

网站使用 GitHub Pages，从 `main` 分支根目录发布，不需要额外构建。网页资源使用相对路径，兼容仓库子路径。

维护档口时修改 `scripts/data.js`；更新缓存资源时同步调整 `index.html` 的资源版本参数与 `sw.js` 的预缓存清单和缓存版本。照片按访问缓存，离线时尚未缓存的照片会回退为应用图标。能否添加到桌面取决于浏览器。

原始 `图片/`、内部开发笔记和本机备份不提交到仓库。补充自己的原图后，可在 Windows PowerShell 中运行 `./scripts/prepare-images.ps1` 生成网页副本；脚本保留原图，不覆盖已有副本。
